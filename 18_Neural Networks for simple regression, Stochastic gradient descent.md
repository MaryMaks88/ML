#### 1. Що таке нейронні мережі (ANN)?
    Штучні нейронні мережі (ANN) — це обчислювальні системи, натхненні біологічними нейронами нашого мозку.
    Це набір математичних функцій, з’єднаних між собою, які здатні знаходити складні закономірності в даних. 
    Їхня головна «фішка» — здатність навчатися на прикладах, а не працювати за жорстко прописаними правилами.

#### 2. Перцептрон (Perceptron)
    Це найпростіша форма нейронної мережі, її «атом». Він приймає кілька вхідних сигналів,
    множить їх на ваги (weights), додає їх і пропускає через функцію активації, щоб видати 0 або 1.

#### 3. Багатошаровий перцептрон (Multi-layer perceptron, MLP)
    Коли ми з’єднуємо багато перцептронів у кілька шарів, ми отримуємо MLP. 
    Це вже повноцінна глибока мережа, яка може вирішувати нелінійні задачі (наприклад, розпізнавати цифри або обличчя).

    1. Чому один нейрон — це замало? (Проблема XOR)
    У 1969 році вчені довели, що звичайний перцептрон не може вирішити задачу XOR 
    (ексклюзивне АБО), де результат дорівнює 1, тільки якщо входи різні ([0,1] або [1,0]).
    
    На графіку ці точки розташовані так, що їх неможливо розділити однією лінією. 
    Щоб вирішити це, нам потрібно "вигнути" простір або провести дві лінії. Для цього і потрібні приховані шари.

    2. Анатомія MLPMLP складається з трьох основних частин:Input Layer (Вхідний шар): 
    Просто передає числа далі.Hidden Layers (Приховані шари): Це "мозок" мережі. 
    Їх може бути один або сотні. Кожен нейрон тут дивиться на комбінації ознак із попереднього шару.
    Output Layer (Вихідний шар): Видає фінальну відповідь.
    
    3. Секретна зброя: Нелінійна активація
    Якщо ми просто з'єднаємо шари нейронів, це математично все одно буде як один великий лінійний нейрон.
    Щоб мережа стала "розумною", після кожного шару ми додаємо нелінійну функцію активації.
    Найпопулярніші сьогодні:ReLU (Rectified Linear Unit): Відсікає все, що менше нуля ($f(x) = \max(0, x)$). 
    Це стандарт для сучасних мереж.Sigmoid: Стискає будь-яке число в діапазон від 0 до 1. 
    Ідеально для вихідного шару, коли треба знайти імовірність.
    
    4. Як MLP "вчиться" (Backpropagation)
    В MLP навчання стає складнішим. Ми використовуємо метод зворотного поширення помилки:
    Forward: Дані проходять крізь усі шари. Отримуємо помилку на виході.
    Backward: Ми йдемо від кінця до початку. 
    Використовуючи похідні (ланцюжкове правило), ми рахуємо: 
    "Наскільки сильно кожна вага в кожному шарі вплинула на фінальну помилку?"
    Update: Оновлюємо всі тисячі (або мільйони) ваг одночасно.Проста аналогія
    
    Уяви, що ти вчиш дитину розпізнавати собаку:Перший шар нейронів помічає прості лінії (вуха, хвіст).
    Другий шар комбінує ці лінії у складніші форми (морда, чотири лапи).Третій шар розуміє: "Якщо є морда, лапи і хвіст — це собака".

#### 4. Структура нейронної мережі
    Типова мережа складається з трьох типів шарів:
    Вхідний шар (Input Layer): приймає сирі дані (пікселі фото, числа тощо).
    Приховані шари (Hidden Layers): тут відбувається вся «магія» обробки та виділення ознак.
    Вихідний шар (Output Layer): видає фінальний результат (прогноз).

#### 5. Як мережа працює: Forward & Backward Propagation
    Щоб мережа навчилася, вона має пройти через два цикли:
    
    Forward Propagation (Пряме поширення)
    Дані проходять крізь мережу від входу до виходу. Кожен нейрон передає сигнал далі, 
    поки ми не отримаємо передбачення. На цьому етапі мережа зазвичай помиляється (особливо на початку).
    
    Backward Propagation (Зворотне поширення помилки)
    Це процес «роботи над помилками». Мережа порівнює свій результат із правильним і обчислює помилку. 
    Потім ця помилка передається назад через мережу, щоб зрозуміти, які саме ваги нейронів найбільше «винуваті» в помилці.

#### 6. Оптимізація: Gradient Descent та Learning Rate
    Gradient Descent (Градієнтний спуск)
    Це алгоритм, який мінімізує помилку. Уяви, що ти в тумані на горі й хочеш спуститися в саму низину (мінімальна помилка).
    Ти робиш крок у напрямку найбільшого схилу вниз.
    
    Stochastic Gradient Descent (SGD): замість того, щоб рахувати помилку для всіх даних одразу (що довго), 
    SGD рахує її для кожного окремого прикладу або маленької групи (батчу). Це швидше і допомагає не «застрягти» в локальних ямах.
    
    Learning Rate (Швидкість навчання)
    Це розмір кроку нашого «спуску».
    
    Якщо крок завеликий — ти можеш перестрибнути низину.
    
    Якщо крок замалий — навчання триватиме вічність.

#### 7. Передбачення (Predictions)
    Коли мережа навчена (ваги налаштовані), етап зворотного поширення вимикається.
    Ви просто подаєте нові дані на вхід, вони проходять через Forward Propagation,
    і на виході ви отримуєте результат (наприклад, "Це фото кота з імовірністю 98%").

#### Simple Perceptron

```python
import numpy as np

# Функція активації (Step function)
def activation(x):
    return 1 if x >= 0 else 0

# Вхідні дані (X1, X2) та правильні відповіді (y)
inputs = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
outputs = np.array([0, 0, 0, 1])

# Ініціалізація ваг та швидкості навчання
weights = np.array([0.0, 0.0])
bias = 0.0  # Зміщення
learning_rate = 0.1

# Навчання (Епохи)
for epoch in range(10):
    for i in range(len(inputs)):
        # Forward propagation (прогноз)
        total_input = np.dot(inputs[i], weights) + bias
        prediction = activation(total_input)
        
        # Обчислення помилки
        error = outputs[i] - prediction
        
        # Оновлення ваг (Gradient Descent в дії)
        weights += learning_rate * error * inputs[i]
        bias += learning_rate * error
        
print(f"Навчені ваги: {weights}, Bias: {bias}") #Навчені ваги: [0.2 0.1], Bias: -0.20000000000000004
```

#### Simple MLP

```python
from sklearn.neural_network import MLPClassifier

# Вхідні дані для XOR
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
# Очікувані результати (1, якщо входи різні)
y = np.array([0, 1, 1, 0])

# Створюємо MLP:
# hidden_layer_sizes=(4,) — один прихований шар з 4 нейронами
# activation='relu' — функція активації ReLU
# learning_rate_init=0.1 — наша швидкість навчання
mlp = MLPClassifier(hidden_layer_sizes=(4,), 
                    activation='relu', 
                    solver='adam', 
                    max_iter=1000, 
                    learning_rate_init=0.1,
                    random_state=1)

# Навчаємо модель
mlp.fit(X, y)

# Перевіряємо передбачення
predictions = mlp.predict(X)
print(f"Результати XOR: {predictions}") #Результати XOR: [0 1 1 0]
```
