### 1. KNN Regressor: Метод "Скажи мені, хто твій сусід"
    Уяви, що ти знайшла на вулиці гарний камінець і хочеш знати, скільки він важить.
    Ти дивишся на 3 схожих камінці поруч, які ти вже важила.
    Якщо вони важать приблизно 100 грамів, то і твій, швидше за все, важить стільки ж.
    
    KNN (K-Nearest Neighbors) — це алгоритм, який шукає «сусідів» (схожі дані) і каже: 
    "Оскільки ці 5 прикладів схожі на твій, я візьму їхнє середнє значення і дам тобі відповідь".

### 2. Scaling (Масштабування): Щоб робот не заплутався
    Уяви, що ми порівнюємо слона і мураху.
    Зріст слона: 3 метри.
    Вага мурахи: 10 міліграмів.
    
    Число 10 більше за 3, але ми ж знаємо, що слон величезний! 
    Робот бачить тільки цифри і може подумати, що мураха «головніша», бо в неї 10. 
    Scaling — це як привести все до однієї лінійки (наприклад, від 0 до 1), щоб робот порівнював чесно.

### 3. RMSE та MAE: Як ми сваримо робота за помилки
    Коли робот вгадує, він помиляється. Нам треба знати, наскільки сильно.
    MAE (Mean Absolute Error): Це просто середня помилка. 
    Якщо робот помилився на 2 грн, потім на 4 грн — в середньому помилка 3 грн. Все чесно і зрозуміло.
    
    RMSE (Root Mean Squared Error): Цей показник дуже суворий. Якщо робот помилився трошки — він його майже не сварять. 
    Але якщо він помилився дуже сильно (наприклад, замість 10 грн сказав 1000) — RMSE «штрафує» його величезним числом.

\\\\\\\\\\\Code\\\\\\\\\\\\\\

```python
    import pandas as pd
    import numpy as np
    from sklearn.model_selection import train_test_split
    from sklearn.preprocessing import StandardScaler
    from sklearn.neighbors import KNeighborsRegressor
    from sklearn.metrics import mean_absolute_error, mean_squared_error
    
    data = {
        "висота_куща": [50, 80, 150, 40, 120, 200, 45, 110],
        "вік_куща": [1, 2, 5, 1, 4, 8, 1, 3],
        "кількість_ягід": [20, 45, 120, 15, 100, 250, 18, 90]
    }
    
    df = pd.DataFrame(data)
    
    X = df[["висота_куща", "вік_куща"]]
    y = df["кількість_ягід"]
    
    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(X)
    
    model = KNeighborsRegressor(n_neighbors=2)
    model.fit(X_scaled, y)
    
    y_pred = model.predict(X_scaled)
    
    mae = mean_absolute_error(y, y_pred)
    rmse = np.sqrt(mean_squared_error(y, y_pred))
```
